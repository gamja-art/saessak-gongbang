# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
새싹 공방의 식물·테라리움 원데이 클래스를 소개하고, 데이트하는 커플에게 수업 예약 문의를 받는 사이트.

## 2. 손님
- 누가: 데이트하는 커플
- 어디서 알고 오나: 인스타그램 (프로필 링크·게시물을 보고 들어옴)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (2인 기준)
2. 수업 시간·가능한 날
3. 위치·주차

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·작품 사진 (사장님이 직접 찍은 테라리움 완성품·수업 현장 사진)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 데이트 클래스 예약 문의
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 버튼
2. 어떤 클래스인가요 — 둘이 함께 만드는 테라리움, 만든 작품은 가져감 (작품 사진)
3. 궁금한 것 세 가지 — 가격(2인) · 수업 시간·가능한 날 · 위치·주차 (정해질 때까지 "준비 중")
4. 후기 자리 (비워 둠)
5. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 희망 날짜·시간
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

> 사이트에는 정해질 때까지 "준비 중"으로 표시하고, 숫자를 지어 넣지 않는다.

## 9. 이번에 넣지 않을 것
- 결제
- 회원가입·로그인
- 예약 달력 (빈 날짜를 골라 바로 확정하는 기능)
- 알림 메일·문자

## 10. 첫 화면 한 문장 후보
1. 둘이 함께 키우는 작은 숲, 새싹 공방 테라리움 데이트 클래스
2. 이번 주말, 둘만의 테라리움을 만들어 집에 가져가세요
3. 손재주 없어도 괜찮아요. 함께 만드는 초록 데이트

## 11. 다음에 할 것
- 작품 사진 3장을 images/work-1.jpg ~ work-3.jpg 로 넣기 (지금은 샘플 그림)
- 가격·수업 시간·위치·주차·연락 방법 확정 후 8번과 사이트에 채우기
- 실제 손님 후기가 생기면 후기 자리 채우기
- 예약 달력, 알림 메일·문자, 회원가입·로그인(개인정보 처리방침 필요), 결제 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (문의 저장이 '예'이므로) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
